CSV Format Help
How to get your contacts into M2 Luxuries
📱 From iPhone / iCloud
1. Go to icloud.com → Contacts
2. Select all → Export vCard
3. Use a converter like csvjson.com to convert to CSV
4. Import the CSV here
📧 From Google Contacts
1. Go to contacts.google.com
2. Click Export → Google CSV
3. Import that file here directly
📄 Custom CSV Format
Your CSV can have any of these column names:
Name, First Name, Last Name, Phone, Mobile, Email, Notes, Vehicle

At minimum you need a Name or First Name column.
Example CSV:
Name,Phone,Email,Vehicle
John Smith,(555)123-4567,john@email.com,2023 BMW M3
Jane Doe,(555)987-6543,jane@email.com,2024 Porsche 911
